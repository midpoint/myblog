原创自留地君 教育技术学自留地

每次演讲，总会有人问：

您的这个聚光灯效果激光笔是怎么弄的？

你是如何将自己的实时头像添加到演示文稿上面的？

想起朋友们每次问到的这些问题，我就想是否应该专门撰写微信公众号推文，把这些大家如此喜欢而真心只能算是“雕虫小技”的把戏分享给朋友们。

今天，我们就在这篇推文中先把网页交互给说清楚。

上课的时候，用一体机、机房演示的时候，你一定遇到过：

屏幕上信息一大堆，学生的眼睛却不知道往哪看；

想圈个重点，只能干巴巴地说“看这里看这里”。

其实，网页本身就能变成一套演示系统——这篇文章把教学里常用的 46 个网页互动整理成五大类，每个都配了课堂场景。

**<u>注意力引导：把目光钉在一个点上 </u>**

核心逻辑：屏幕上的信息越少，学生听得越进去

1、暗幕 / 遮罩——全场变暗，只亮当前讲的区域，讲题、看图、走代码都好使。

2、聚光灯——圆形高亮跟着鼠标走，指哪亮哪。（网页版按 L 立刻体验）

3、放大镜——局部放大，讲图表细节、代码、生字笔画时特别管用。（网页版按 M 试试）

4、激光笔 / 光点高亮——带拖尾的红点，指哪打哪。（网页版按 X 划两下）

5、点击波纹——点了哪里，屏幕上荡开一圈涟漪，录微课学生也能看清你的操作。

6、十字准星——软件操作课的精确指针，坐标、对齐一目了然。

7、黑白屏——B 黑屏、W 白屏，临时把全班的眼睛还给你。

8、局部模糊——答案先糊上，讲完了再揭晓。

**<u>标注讲解：讲过的痕迹就是板书 </u>**

核心价值：痕迹可以留下来、发出去

9、自由画笔——直接在网页上圈画重点。（网页版按 A 可以直接画）

10、荧光笔——半透明高亮，划课文、公式、代码都不挡字。

11、箭头 / 直线——标出流程、方向、因果关系。

12、矩形 / 圆形框选——框住关键区域，讲阅读理解定位句正好。

13、文字批注——页面任意位置写说明。

14、橡皮 / 撤销 / 清空——批注工具的安全网，画错了随手撤。

15、截图导出——讲完把标注图存下来发到班级群，缺席的学生也能看。

16、白板模式——一键切到空白画布，现场推导、列提纲。

**<u>内容展开：节奏归讲的人 </u>**

答案不提前出现，思考才来得及发生

17、点击揭示 / 逐步显示——点一下出一条，控住讲解节奏。

18、悬停提示 Tooltip——鼠标放到术语上弹出解释，差生优生各取所需。

19、热点 / 热区——解剖图、地图、电路图上的可点击区域，点开弹讲解。

20、选项卡——同一区域切换不同内容，一屏当多屏用。

21、折叠面板——常见问题、详细步骤按需展开。

22、翻转卡片——正面问题背面答案，单词卡、古诗文默写神器。

23、图片对比滑块——拖动看「改动前 / 改动后」，作文升格讲解直观。

24、缩放拖拽 / 无限画布——思维导图、知识结构图整体局部随意切换。

25、图表高亮 / 数据钻取——点柱状图某一年，弹出明细数据。

26、代码逐行高亮——信息科技课逐行走代码，学生跟着读。

27、公式逐步推导——数学、物理分步展开，每步停顿让学生先猜。

28、3D 模型旋转 / 拆解——心脏、齿轮、建筑结构转着看。

**<u>导航控制：现场节奏主人是你 </u>**

基础但必备——控场全靠它们

29、目录 / 缩略图导航——复习课一键跳回任意一页。

30、进度条——讲到哪一眼看到，学生心里有数。

31、键盘快捷键——翻页、黑白屏、批注全在键盘上。

32、演讲者视图——备注、下一页、计时器都在你手里。

33、手机遥控——边走边讲，手机变翻页器和聚光灯。

34、计时器 / 倒计时——限时讨论、随堂小测。（网页版按 T 呼出）

35、全屏 / 书签跳转——基础但天天用。

36、二维码——扫码进问卷、资料包、互动页，课后延伸一扫就走。

**<u>互动参与：从“在看”变成“在玩” </u>**

参与感最强的三类之一，气氛担当

37、投票 / 选择题——扫码答题，实时出柱状图，错误率当场可见。

38、实时问答墙——学生匿名提问、点赞排序，内向的孩子也敢问。

39、词云——课前热身收关键词，“说到春天你想到什么？”一秒成云。

40、弹幕——热闹但容易跑偏，慎用。

41、举手 / 点赞 / 表情反馈——快速探班：“听懂的扣 1”。

42、随机点名 / 抽奖转盘——公平又刺激，替代“有没有同学自愿”。

43、分组计分 / 抢答器——课堂竞赛标配，小组合作学习好搭档。

44、拖拽排序 / 连线 / 匹配——历史事件排序、单词配对，动手又动脑。

45、分支选择 / 剧情式演示——学生选 A 走 A 线，选 B 走 B 线，课程自己做主。

46、协作白板——全班同屏写想法，小组汇报一屏收齐。

有这么多工具和交互方式，到底应该怎么选？

**<u>场景速配：你的课堂先用哪个 </u>**

不用全上，结合你的教学设计，根据你的现实需求，挑一两个先用起来。
